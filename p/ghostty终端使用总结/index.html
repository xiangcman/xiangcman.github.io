Ghostty终端使用总结

2026-04-03
阅读时长: 7 分钟

Ghostty 是一个现代化的终端模拟器，由 mitchellh 开发，以其出色的性能和原生 macOS 集成而闻名。本文将详细介绍 Ghostty 在 macOS 上的安装、配置和快捷键使用方法。

安装

Homebrew 安装（推荐） 

1

brew install ghostty

安装完成后，你可以通过 Spotlight 搜索 “Ghostty” 或在终端中输入 ghostty 启动应用。

配置文件

Ghostty 使用简洁的配置文件进行配置，配置文件位置为 ~/.config/ghostty/config。

常用配置项

配置项 说明 示例值

font-size 字体大小 14
window-width 窗口宽度 1200
window-height 窗口高度 800
theme 主题名称 dracula, monokai, solarized-dark
background-opacity 背景透明度 0.95
cursor-style 光标样式 block, underline, bar
cursor-blink 光标闪烁 true, false

你也可以在 Ghostty 中按 Cmd + . 直接进入快捷键浏览模式。

标签页管理

快捷键 功能
Cmd + T 新建标签页
Cmd + W 关闭当前标签页
Cmd + 1-9 切换到第 N 个标签页
Cmd + Tab 切换到下一个标签页
Cmd + Shift + Tab 切换到上一个标签页
Cmd + Left/Right 切换相邻标签页
Cmd + Option + Left/Right 移动当前标签页位置

复制粘贴

快捷键 功能
Cmd + C 复制选中文本
Cmd + V 粘贴文本
Cmd + Shift + V 粘贴并清除格式
Cmd + Shift + C 进入选择模式进行复制

搜索功能

快捷键 功能
Cmd + F 打开搜索框
Cmd + G 查找下一个
Cmd + Shift + G 查找上一个
Escape 退出搜索模式

面板分割

Ghostty 支持水平和垂直分割窗口：

快捷键 功能
Cmd + D 水平分割
Cmd + Shift + D 垂直分割
Cmd + ] 切换到下一个面板
Cmd + [ 切换到上一个面板
Cmd + W 关闭当前面板

其他常用快捷键

快捷键 功能
Cmd + K 清屏（相当于 clear）
Cmd + + 放大字体
Cmd + - 缩小字体
Cmd + 0 重置字体大小
Cmd + . 进入快捷键配置模式
Cmd + , 打开配置文件

快速下拉终端（Quake 模式）

Ghostty 支持类似 Quake 游戏的下拉终端效果，终端可以从屏幕顶部快速滑入/滑出。

# 设置下拉快捷键（默认 Cmd + Shift + Space）

常用命令行参数

参数 说明 示例
-e, –command 启动时执行的命令 ghostty -e “htop”

–working-directory 指定工作目录 ghostty -d ~/projects
–title 设置窗口标题 ghostty –title “Server”
–fullscreen 全屏模式 ghostty –fullscreen
–maximized 最大化窗口 ghostty –maximized
+list-themes 列出所有主题 ghostty +list-themes
+list-keybinds 列出所有快捷键 ghostty +list-keybinds
+list-fonts 列出所有可用字体 ghostty +list-fonts
+list-actions 列出所有可用动作 ghostty +list-actions
+list-features 列出所有功能特性 ghostty +list-features
–help 显示帮助信息 ghostty –help
–version 显示版本信息 ghostty –version

配置文件位置说明

Ghostty 的配置文件位置遵循 XDG 规范：

1
2
3
4
5

# 配置文件位置
~/.config/ghostty/config

# 你也可以使用环境变量指定配置目录
export GHOSTTY_CONFIG_DIR=~/.config/ghostty

配置文件的加载顺序

  1. $XDG_CONFIG_HOME/ghostty/config (默认 ~/.config/ghostty/config)
  2. $HOME/.ghostty (旧版本兼容)
  3. 命令行 --config-file 参数指定的文件

常见问题

Q: 如何重置所有配置？

A: 删除配置文件 ~/.config/ghostty/config 即可恢复默认设置：

1

rm ~/.config/ghostty/config

Q: Ghostty 支持 SSH 代理配置吗？

A: 支持，可以在配置文件中设置代理：

1
2

http-proxy = http://127.0.0.1:7890
https-proxy = http://127.0.0.1:7890

Q: 如何调整光标闪烁速度？

A: Ghostty 不提供单独的光标闪烁速度配置，但可以通过以下方式控制：

1

cursor-blink = false  # 禁用闪烁

Q: 如何禁用终端提示音？

A: 在配置文件中添加以下内容：

1
2

bell = none
visual-bell = false

Q: Ghostty 与其他终端模拟器有什么优势？

A: Ghostty 的主要优势包括：

  • GPU 加速渲染，性能出色
  • 原生 macOS 集成
  • 配置文件简洁易用
  • 支持 GPU 加速的字体渲染
  • 内置丰富的主题

Q: 如何导出/备份配置？

A: 配置文件位于 ~/.config/ghostty/config，直接复制该文件即可备份：

1
2
3
4
5

# 备份配置
cp ~/.config/ghostty/config ~/backup/ghostty-config

# 恢复配置
cp ~/backup/ghostty-config ~/.config/ghostty/config

总结

Ghostty 是一个高性能、功能丰富的终端模拟器，特别适合 macOS 用户。通过合理的配置和快捷键使用，可以大幅提升终端使用体验。建议从基础配置开始，逐步根据个人习惯调整，找到最适合自己的配置方案。
