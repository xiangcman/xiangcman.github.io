Yazi文件管理器使用总结

2026-04-03
阅读时长: 4 分钟

Yazi 是一个用 Rust 编写的极速终端文件管理器，提供了丰富的快捷键操作和强大的文件预览功能。本文将详细介绍 Yazi 的安装、配置和快捷键使用方法。

安装

Homebrew 安装（推荐） 

1

brew install yazi ffmpegthumbnailer jq poppler fd ripgrep zoxide

cargo 安装 

1

cargo install yazi-cli yazi-flosk

Shell Wrapper 配置

为了在退出 Yazi 后自动切换到对应目录，需要配置 shell wrapper。以下是各 shell 的配置方法：

Zsh / Bash

function y() {
	local tmp="$(mktemp -t "yazi-cwd.XXXXXX")"
	command yazi "$@" --cwd-file="$tmp"
	IFS= read -r -d '' cwd < "$tmp"
	[ -n "$cwd" ] && [ "$cwd" != "$PWD" ] && [ -d "$cwd" ] && builtin cd -- "$cwd"
	rm -f -- "$tmp"
}

function y
    set tmp (mktemp -t "yazi-cwd.XXXXXX")
    command yazi $argv --cwd-file="$tmp"
    set cwd (cat "$tmp")
    if test -n "$cwd" -a "$cwd" != "$PWD" -a -d "$cwd"
        builtin cd -- "$cwd"
    end
    rm -f -- "$tmp"
end

def --env y [...args] {
    let tmp = (mktemp -t "yazi-cwd.XXXXXX")
    ^yazi ...$args --cwd-file $tmp
    let cwd = (open $tmp)
    if $cwd != $env.PWD and ($cwd | path exists) {
        cd $cwd
    }
    rm -fp $tmp
}

function y {
    $tmp = (New-TemporaryFile).FullName
    yazi.exe $args --cwd-file="$tmp"
    $cwd = Get-Content -Path $tmp -Encoding UTF8
    if ($cwd -and $cwd -ne $PWD.Path -and (Test-Path -LiteralPath $cwd -PathType Container)) {
        Set-Location -LiteralPath (Resolve-Path -LiteralPath $cwd).Path
    }
    Remove-Item -Path $tmp
}

快捷键

Yazi 提供了丰富的快捷键，以下是完整的快捷键汇总：

导航快捷键

快捷键 备选键 功能
h ← 返回上级目录
j ↓ 光标上移
k ↑ 光标下移
l → 进入目录
K - 预览区域上移 5 行
J - 预览区域下移 5 行
gg - 跳到文件列表顶部
G - 跳到文件列表底部
z - 通过 fzf cd 到目录或打开文件
Z - 通过 zoxide cd 到目录
g + Space - 通过交互式提示 cd 到目录

选择快捷键

快捷键 功能
Space 切换当前文件选中状态
Ctrl + Space 切换当前文件选中状态（备选）
v 进入可视化模式（选中模式）
V 进入可视化模式（取消选中模式）
Ctrl + a 全选所有文件
Ctrl + r 反选所有文件
Esc 取消选择

文件操作快捷键

快捷键 功能
Enter 打开选中文件
o 打开选中文件
O 交互式打开选中文件
Tab 显示文件信息
y 复制（yank）选中文件
x 剪切选中文件
p 粘贴已复制的文件
P 粘贴并覆盖已存在的文件
Y / X 取消 yank 状态
d 删除到回收站
D 永久删除
a 创建文件（以 / 结尾创建目录）
r 重命名选中文件
. 显示/隐藏隐藏文件

命令执行快捷键

快捷键 功能
; 执行 shell 命令（非阻塞）
: 执行 shell 命令（阻塞直到完成）
- 符号链接（绝对路径）
_ 符号链接（相对路径）
Ctrl + - 硬链接已复制的文件

复制路径快捷键

快捷键 功能
c → c 复制文件路径
c → d 复制目录路径
c → f 复制文件名
c → n 复制文件名（不含扩展名）

过滤和搜索快捷键

快捷键 功能
f 过滤文件
/ 向下查找文件
? 向上查找文件
n 跳到下一个匹配项
N 跳到上一个匹配项
s 使用 fd 搜索文件名
S 使用 ripgrep 搜索文件内容
Ctrl + s 取消搜索

排序快捷键

快捷键 功能
, → m 按修改时间排序
, → M 按修改时间倒序排序
, → b 按创建时间排序
, → B 按创建时间倒序排序
, → e 按扩展名排序
, → E 按扩展名倒序排序
, → a 字母排序
, → A 字母倒序排序
, → n 自然排序
, → N 自然倒序排序
, → s 按文件大小排序
, → S 按文件大小倒序排序
, → r 随机排序

标签页管理

快捷键 功能
t 创建新标签页（使用当前目录）
1 - 9 切换到第 N 个标签页
[ 切换到上一个标签页
] 切换到下一个标签页
{ 与上一个标签页交换位置
} 与下一个标签页交换位置
Ctrl + c 关闭当前标签页

常见问题

Q: 如何显示隐藏文件？

A: 按 . 键可以切换隐藏文件的显示。

Q: 如何恢复误删的文件？

A: Yazi 默认将文件移到回收站（相当于 trash 命令），可以在回收站中找到并恢复。

Q: 如何永久删除文件而不是移到回收站？

A: 按 D 键会永久删除选中文件，此操作不可恢复。

Q: 如何使用 zoxide 快速跳转？

A: 按 Z 键可以使用 zoxide 快速跳转到常用目录。

Q: 如何搜索文件内容？

A: 按 S 键可以使用 ripgrep 搜索当前目录下的文件内容。

Q: Yazi 支持哪些终端？

A: Yazi 支持大多数现代终端，包括 iTerm2、kitty、Alacritty、Wezterm 等。某些功能（如图片预览）需要终端支持。

技巧汇总

1. 快速选择多个文件

使用 v 进入可视化模式后，用 j/k 移动光标可以快速选择连续文件。使用 Space 可以单独选择/取消选择文件。

2. 批量重命名

配合可视化选择模式，可以批量选择文件后按 r 进行批量重命名。

3. 使用 fd 快速定位文件

按 s 键使用 fd 工具快速搜索文件，比传统的查找方式更快。

4. 快速切换排序方式

按 , 键加上相应的字母可以快速切换排序方式，如 ,m 按修改时间排序。

5. 使用标签页管理多个目录

按 t 键创建新标签页，可以用 ] 和 [ 快速切换不同的目录。

6. 快速复制路径

选中文件后按 c → c 可以快速复制文件路径，非常方便在终端中使用。

7. 批量创建符号链接

复制文件后（按 y），可以按 - 或 _ 批量创建符号链接。

8. 批量删除文件或文件夹

选中文件后（使用 Space 或 v 进入可视化模式选择），可以按 d 将选中项移到回收站，或按 D 永久删除。删除前建议按 Tab 查看将要删除的文件列表确认无误。

总结

Yazi 是一个功能强大、性能出色的终端文件管理器，其丰富的快捷键设计借鉴了 Vim 的操作方式，让习惯使用 Vim 的用户能够快速上手。通过合理的配置和快捷键使用，可以大幅提升文件管理效率。建议从基础导航开始，逐步掌握选择、复制粘贴等操作，最后根据个人习惯自定义快捷键。
